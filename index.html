Documentación y Esquema de Base de Datos

Cumplimiento de requerimientos de la asignatura de Administración de BD

1. Esquema de Usuarios y Privilegios

DBA Administrador (Root / SysAdmin)

Acceso total mediante GRANT ALL PRIVILEGES. Capacidad para ingresar al Panel de Fábrica, modificar stock directamente, ejecutar procedimientos almacenados y visualizar métricas confidenciales e informes.

API Usuario de Sistema (Web App)

Usuario restringido utilizado por la capa de la aplicación (el código). Privilegios limitados a:
- SELECT en `producto` y `materia_prima`.
- INSERT y SELECT en `pedido` y `detalle_pedido`.
- UPDATE en `producto` (para rebajar stock).

WEB Clientes (Juan Pérez / Restobar)

Entidades almacenadas en la tabla cliente. No tienen acceso directo a MariaDB. Se autentican mediante el sistema web y sus datos (RUT, nombre, tipo de cliente) son leídos de la base de datos para auto-completar transacciones de compras.

2. Documentación de Acciones y Registros

Transacción de Venta (ACID)

Se ejecuta al confirmar el carrito. Garantiza que no se cobre si no hay stock o si falla la base de datos.

START TRANSACTION;
INSERT INTO pedido (rut_cliente, total_venta, estado_pago) VALUES ('18.111.222-3', 7000, 'Pagado');
INSERT INTO detalle_pedido (id_pedido, id_producto, cantidad) VALUES (LAST_INSERT_ID(), 1, 2);
UPDATE producto SET stock_unidades = stock_unidades - 2 WHERE id_producto = 1;
COMMIT;

Procedimiento Almacenado (Producción)

Se invoca desde el Panel de Fábrica. Automatiza la lógica de descontar materias primas (malta, lúpulo) y sumar litros/botellas a la tabla de productos terminados.

CALL sp_cocinar_lote(1); -- 1 = ID de IPA Americana

Consultas de Catálogo (Catálogo Online)

Acción ejecutada automáticamente al entrar como cliente para visualizar la tienda.

SELECT id_producto, estilo, ibu, srm, abv, precio_unitario
FROM producto WHERE stock_unidades > 0;
